# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:
to study the problem statement, SRS document and draw all the UML diagrams of Railway management system.
# SRS (Procedure):
Step 1: Problem Identification
The main problem is the need for a fast, secure, and automated system that allows passengers to perform ticket booking and cancellation

Step 2: Requirement Analysis
Identify user needs (passenger, admin, ttr,ticketcounter ).

Define functional requirements: arrival, availability check, booking and cancel .

Define non-functional requirements: speed, security, reliability, and usability.

Step 3: System Design
Draw UML diagrams to represent the system: Use Case Diagram Class Diagram Activity Diagram Sequence Diagram Communication Diagram Package Diagram Design the database with tables for passenger, admin, ttr,ticketcounter.
